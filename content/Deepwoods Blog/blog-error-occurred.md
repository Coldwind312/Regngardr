###### *Originally posted 2026-06-14*

See, now this is the sort of thing that just infuriates the absolute beans out of me.

It’s not the only thing that does that, I’ll admit; but it’s a bugbear.[^1]

I’ve had the sense for quite a while now that, as the Internet and computer technology has broadly [enshittified](https://en.wikipedia.org/wiki/Enshittification), error messages have been quietly degrading in terms of usefulness.

Here’s an example I had today while trying to save an image file out of Microsoft Photos, having made a quick, sub-GIMP edit.[^2]

![[error-try-later.webp]]

In the event the image isn’t accessible, this is a small one-line error message that flashed up across the top of the screen, and it reads, “Unable to save There was an error while saving. Please try again later.”

Thing is, I know what the error is. I happen to know, because I’m accustomed to it occurring and I’ve had to fix it on a few things. I know that my computer, as a defence against malware trying to install itself, restricts access to a number of ‘controlled folders’, including the folder I was trying to save to. This is a pretty common setting and, in fact, I’m not sure it isn’t on by default. But each program you want to allow to save into a controlled folder has to be authorised in Settings. Photos, for some reason, wasn’t, and this was what caused the error. I go into Settings, add Photos to the exemptions list, and Bingovius is your uncle.

But if you don’t know about controlled folders restrictions already… how does this error message help you? “An error” gives you nothing at all about what the error was. And I’ve complained about obscure error numbers before—like when computers would give you some baffling bit of machine code or say “Process fuckyou.exe failed at Hurdle #001” or whatever, and you could at least type in ‘Hurdle #001’ (or whatever—it was usually just a memory address or something equally obscure) and have a chance of finding a forum where people had reported, and solved, the same issue.

![[exception-error.webp]]
_This is just a random grab off a search for ‘error message’. It isn’t an error I’ve had, but it’s to make the point: you can type this code into a search engine and find discussions of what the problem is and how to fix it._

“An error” gives you absolutely nothing to go on—and yet this seems to be the standard now. Were I a conspiracy-prone drow, I might almost suspect that the software peddlers like Microsoft are deliberately putting up barriers to try to force users to call massively expensive helplines rather than have any means of fixing issues themselves. But I’m sure that’s just an unfortunate side-effect of whatever actual, perfectly benevolent, decision was really behind this.

It’s “Please try again later” that really hacks me off, though. Because that is just actively misleading. If you, as the user, don’t know what this error is being caused by, if you don’t go into your Windows settings and authorise access to your controlled folders by this particular program, application, game, process, whatever, then this problem *will not resolve*. It isn’t going to suddenly get better on its own. Yet this error message actively encourages you to believe that it will. Oh, you’ll think, it must just be some transient condition, this too shall pass, and I’m sure everything will be peachy by this afternoon

_nope_

after tea

after the weekend

after i throw the computer out of the window

_probably not_

Not all things pass. I don’t, that asshole in the Tesla behind you making a meal of how slowly you’re driving won’t, and this error won’t. You have to fix it yourself. But the error message very strongly suggests that all you need do is sit back and wait.

Bring back helpful error messages. Also overthrow capitalism and ban billionaires. Trillionaires… My gods, _trillionaires_ exist now. What a fucked-up world.

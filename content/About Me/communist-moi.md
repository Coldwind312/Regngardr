  - Seeing if I'm a Communist
---
I took IDR Labs' 'Communism Test' to see if I'm a communist.

Turns out I'm 70% of one, which sounds fair enough.

What I think probably pulled my score down, though, is that a lot of the questions were based on whether I think the state should own this, or control that, or regulate the other.

And the problem there is that like some, but I guess maybe not all, other communists, I don't think there should *be* a state. Ultimately, while a transparent and truly accountable representative democracy is a far better version of a state than the oligarchies and tyrannies that have been most governments since the dawn of human civilisation, any state at all is still really only a mechanism of control and hierarchy that we don't need to have.

Which belief honestly makes answering these questions a bit tricky.

Do I think that all means of communication should be centralised in the hands of the state? Well, no - because there shouldn't be a state to do that. The people should collectively control them.

Well, should the state control all aspects of economic production? No, because there shouldn't be a state to do that. The people should control their own work and its output.

And so on.

And I suspect that as far as the test is concerned - which is at [https://www.idrlabs.com/communism/test.php](https://www.idrlabs.com/communism/test.php) if you want to have a go at it (and have a browse round IDR Labs while you're there: their massive array of tests is pretty fascinating if you've got a few spare minutes) - it was probably looking for yesses on these questions. But this is often a problem with online multiple-choice tests like these. Quite often I find that the questions consist of multiple parts and quite often the parts conflict, forcing me into not-fully-suitable answers.

I'm not naive. Well, not about some things. I know this is the point: the questions are framed this way for a reason. The question is, is that reason that those apparent tensions help to provide a better overall result? Or is it that they're trying to manipulate the outcome?

For the record I don't *think* that's the case with IDR. Their tests run from fairly scientifically sound to borderline comical - but I'm reasonably satisfied that they don't have any particular interest in manipulating the results in a specific direction. Though I guess you can never be entirely sure: caveat responsor, obvs.

But it does make me wonder. If they'd provided the option to reject the state as a concept, I wonder how different my result would be?
